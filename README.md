# Interest Over Years Calculator

Basic command line UI for the interest accumulated over the years calculator.


>Easiest to open in Visual Studio and run. Just clone, open, and run.


>Example of application with $50 initial and monthly deposit amount and a 5% interest rate over 10 years.
